# KoduMedia 0.8.56

KoduMedia 0.8.56 improves AirPlay and DLNA playback reliability, with a focus
on iPhone and Samsung television compatibility.

## Highlights

- Safari and iPhone now prefer native HLS whenever the browser supports it, so
  AirPlay receives a network-accessible media URL instead of a browser-only
  blob source.
- Samsung and other DLNA clients use MPEG-TS HLS for non-direct playback.
- DLNA playback waits for a 12–20 second ready buffer before starting, reducing
  repeated buffering during playback.
- Compatible 4K/HEVC media remains on Direct Play or remux paths.
- Required DLNA video transcoding uses a stable 1080p H.264 SDR fallback.
- Bundled FFmpeg and FFprobe are updated to Gyan FFmpeg 9.0.2 Essentials.

## Installation

1. Download `kodumedia-0.8.56-windows-x64.zip` below.
2. Verify it with the accompanying `.sha256` file if desired.
3. Extract the complete ZIP into a writable folder.
4. Run `start-kodumedia.cmd`.

Existing users can install the same ZIP through KoduMedia's updater in
**Settings → System status → KoduMedia update**.

> KoduMedia is intended for a trusted private network. Do not expose port 8096
> directly to the public internet.
