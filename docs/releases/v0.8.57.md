# KoduMedia 0.8.57

KoduMedia 0.8.57 is a critical playback hotfix for the browser player.

## Fixed

- Movies and episodes no longer remain indefinitely on the initial buffering
  screen when an HLS transcode reaches roughly ten seconds but the quality plan
  requests a 14–20 second encoder buffer.
- Browser playback now starts with a bounded buffer target and may proceed
  after six seconds when the media element confirms that playable data exists.
- Rebuffer recovery also uses a bounded browser target instead of waiting
  forever for a larger server-side quality target.
- Samsung and other DLNA playback keeps its independent 12–20 second
  server-side ready buffer. The AirPlay and MPEG-TS DLNA fixes from 0.8.56 are
  unchanged.

## Verification

- Player buffering regression tests pass.
- All 104 frontend tests pass.
- The production Vite bundle builds successfully.

## Install

1. Download `kodumedia-0.8.57-windows-x64.zip` from this release.
2. Stop the existing KoduMedia server.
3. Extract the complete ZIP to a writable folder.
4. Keep a backup of the existing `data` folder and copy it into the new folder.
5. Run `start-kodumedia.cmd`.

KoduMedia is intended for trusted private networks. Do not expose port `8096`
directly to the public internet.
