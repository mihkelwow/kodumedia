ThemerrDB
---------
KoduMedia queries the public ThemerrDB data endpoint by TMDb series ID to find
the curator-provided YouTube theme reference. ThemerrDB audio is not bundled in
KoduMedia; successfully resolved audio is cached locally by the user's server.

Upstream project: https://github.com/LizardByte/ThemerrDB
Service: https://app.lizardbyte.dev/ThemerrDB/

Chromaprint / fpcalc 1.6.0
-------------------------
When the user enables AcoustID fingerprinting and configures a free API key,
the Windows server may download the official Chromaprint fpcalc 1.6.0 binary
from the upstream GitHub release. KoduMedia verifies the archive against the
pinned SHA-256 value before extracting or executing it and stores the upstream
license text beside the tool in data/music-metadata/tools/.

Upstream project: https://acoustid.org/chromaprint
Release source: https://github.com/acoustid/chromaprint/releases/tag/v1.6.0

shazamio-core fingerprint implementation
----------------------------------------
KoduMedia's native Go Shazam signature generator adapts the fingerprint
algorithm and binary signature format from shazamio-core. The upstream project
is MIT-licensed. KoduMedia sends only a compact generated acoustic signature,
not the original audio file, to an unofficial reverse-engineered Shazam
recognition endpoint. This endpoint is not an official documented public API
and may change or rate-limit requests.

Upstream project: https://github.com/shazamio/shazamio-core

License: MIT; complete text in tools/licenses/shazamio-core-MIT.txt
